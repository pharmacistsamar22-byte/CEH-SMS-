# CEHSMS — نظام تتبع الحالات الكيميائية والحرجة (Streamlit، متعدد الصفحات)

## التشغيل السريع
```bash
pip install -r requirements.txt
streamlit run app.py
```
بيانات الدخول: `owner` / `Owner#2025` (مالك النظام) أو `admin` / `1234` (قائد فريق)

بدون إعداد Google Sheets، البيانات تُحفظ محليًا في `data/` — طريقة مؤقتة للتجربة فقط
(بتتمسح على أي استضافة سحابية بعد كل إعادة تشغيل). راجع قسم "التخزين الدائم" تحت.

## أهم الميزات

### 1. التصنيف السمي الشامل (`toxicology_classification.py`)
وحدة مستقلة قائمة بذاتها، فيها **8 فئات رئيسية** و**38 فئة فرعية** و**55 مادة
إرشادية** — نفس الطريقة اللي بتشتغل بيها مراكز السموم الحديثة:

1. Chemical Toxicology (المواد الكاوية، الغازات السامة، المذيبات، المعادن الثقيلة، الكحولات السامة)
2. Pesticide Toxicology (فوسفات عضوي، كارباميت، مبيدات قوارض، مبيدات أعشاب، مبيدات حشرية)
3. Pharmaceutical Poisoning (مسكنات، مهدئات، مضادات اكتئاب/ذهان، أدوية قلبية، أفيونيات)
4. Biological Toxins & Envenomation (لدغات أفاعي/عقارب/عناكب، سموم بحرية، لسعات حشرية)
5. Food & Natural Toxins (تسمم غذائي، فطر، نباتات، سموم فطرية)
6. Occupational & Industrial Exposure (مصانع، بتروكيماويات، زراعة، معامل)
7. Chemical Burns & Decontamination (جلد، عين، استنشاق، تعرض جماعي)
8. CBRN Toxicology (عوامل كيميائية/بيولوجية/إشعاعية)

بالإضافة لخيار **"مادة كيميائية أخرى"** لأي شيء غير مصنّف.

### 2. المادة المشتبه بها — "مادة كيميائية أخرى"
في صفحة "بيانات الحالة"، لو المادة مش موجودة بالقائمة، تقدر تختار
**"➕ مادة أخرى غير موجودة بالقائمة..."** فيظهر نموذج لـ:
- كتابة اسم المادة الكيميائية ومعلومات عنها (الاسم التجاري، CAS، خطورة التعرض، التخزين، PPE، الإسعافات الأولية)
- **رفع ملف SDS خاص بالمادة (PDF)** مباشرة
- إدخال بريد مسؤول النظام لإخطاره بطلب المراجعة

المادة تُحفظ فورًا بحالة **"بانتظار اعتماد المسؤول"**. ملف الـSDS المرفق
**مايظهرش لغير المالك إلا بعد الاعتماد الرسمي** من صفحة "قاعدة بيانات SDS".

### 3. اللوجو
لوجو النظام (`assets/logo.png`) ظاهر في شاشة تسجيل الدخول والقائمة الجانبية
لكل الصفحات.

### 4. تصدير البيانات وإرسالها
- تصدير Excel (.xlsx) حقيقي، بالإضافة لـ CSV و JSON
- إرسال بريد إلكتروني فعلي عبر SMTP مع إرفاق تقرير Excel

### 5. تخزين دائم اختياري عبر Google Sheets
راجع تعليمات الإعداد في `.streamlit/secrets.toml.example` — بمجرد إضافة بيانات
الاتصال، التطبيق بيحفظ سجل الحالات والمواد المضافة يدويًا (بما فيها ملفات SDS
المرفقة، بحد أقصى ~30 كيلوبايت للملف الواحد بسبب حدود خلية Google Sheets)
بشكل دائم مش بيتمسح مع كل إعادة تشغيل.

⚠️ **ملحوظة:** لو الملف المرفوع أكبر من الحد المسموح في وضع Google Sheets،
هيتحفظ بيانات المادة عادي لكن من غير الملف، مع تنبيه واضح للمستخدم وقت الرفع.

## طريقة تسجيل الدخول والصلاحيات
| المستخدم | كلمة المرور | الصلاحيات |
|---|---|---|
| `owner` | `Owner#2025` | كل الصفحات + تصدير البيانات + إرسال البريد + اعتماد/رفض المواد الجديدة + تحميل ملفات SDS المعلّقة |
| `admin` | `1234` | تسجيل الحالات ومتابعتها فقط (بدون رؤية بيانات المرضى الشخصية أو التصدير) |

⚠️ بيانات الدخول دي **Demo فقط** مكتوبة داخل `common.py` — لأي استخدام فعلي،
انقلها لـ `st.secrets`.

## ملاحظة عن جودة بيانات SDS
البيانات الأساسية الـ286 مادة مستخرجة آليًا من "الدليل الإرشادي لطرق التداول
الآمن للمواد الكيميائية بالمنشآت الصحية". يُنصح بمراجعة أي مادة حرجة من الدليل
الأصلي قبل الاعتماد عليها في قرار طبي.
